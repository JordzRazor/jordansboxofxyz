Sniper

Code written in a browser chat, landing in the right file on disk — no copy-paste round trip. A "→ Claude" button appears on every code block; one click ships it to a relay running on your own machine, which stages it for review before anything touches a file.

Two ways in. The app: unzip, double-click, and the chat opens in a tab inside it with the buttons already there — nothing else to install. The original: a userscript in your own browser and a few Python files you can read line by line.

No credential ever leaves the browser you're signed into. The relay binds to loopback only, and drops are staged, never applied blind.

What this place is for

This is a small, personal shopfront — not a portfolio, not a product. Just a handful of interactive pieces built to be looked at when the day has a spare corner in it: waiting on a build, waiting on a meeting, waiting on nothing in particular.

Nothing here asks you to sign in, install anything, or pay attention for very long. Close the tab whenever.

  • Built to be gentle on old and low-end laptops — capped particle counts, capped frame work, everything pauses when the tab isn't visible.
  • WebGPU pieces detect support automatically and quietly fall back to WebGL — nothing ever just breaks.
  • No account system, no tracking beyond basic ad delivery (see below), no dark patterns.
